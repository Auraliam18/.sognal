# brain/research — تحقیق‌های پرسش-محور

هر تحقیق یک فایل: `YYYY-MM-DD-<slug>.md` با ساختار اجباری:
پرسش / ماشه (کدام رویداد غیرعادی) / فرضیه / شواهد (منبع+تاریخ) /
پیاده‌سازی پیشنهادی / ریسک‌ها / طرح تست / وضعیت
(OPEN → BACKTESTED → PAPER → REVIEWED → PRODUCTION یا REJECTED).

قواعد: تحقیق بدون پرسش مشخص شروع نمی‌شود. یافتهٔ بیرونی مرجع نیست، شاهد
است. هیچ نتیجه‌ای مستقیم وارد منطق تولید نمی‌شود — فقط از مسیر
RESEARCH → BACKTEST → PAPER → REVIEW → PRODUCTION.
تحقیق از تولید ایزوله است: این پوشه هیچ‌وقت توسط ورک‌فلوهای تولید خوانده
نمی‌شود؛ فقط انسان/ایجنت بازبین از آن به کد می‌برد.

پرسش‌های باز: `open-questions.md`.
