# سلسله‌مراتب منابع — هوش اردر بلاک (بند ۲۲ سند حمید)

استفاده به همین ترتیب؛ منبع پایین‌تر هرگز منبع بالاتر را نقض نمی‌کند.

## Tier 1 — ریزساختار بازار (معتبرترین)
- cmegroup.com — آموزش/پژوهش نقدینگی، دفتر سفارش (LOB)، اجرا
- coinbase.com/institutional و docs.cdp.coinbase.com — گزارش‌های نهادی،
  عمق بازار، ریزساختار کریپتو
- binance.com و academy.binance.com — عمق بازار، اسپرد، اثر قیمتی، اجرا

## Tier 2 — تعاریف مفهومی ICT/SMC
فقط برای «تعریف» Order Block / Breaker / Mitigation / MSS / FVG /
Premium-Discount (PD Arrays). آموزش مفهومی ≠ اثبات آماری — هر مفهوم قبل
از هر اثری روی دادهٔ تاریخی خودمان تست می‌شود.

## Tier 3 — پژوهش دانشگاهی
Google Scholar / SSRN / arXiv دربارهٔ ریزساختار، LOB، عدم‌توازن سفارش،
اثر بازار (market impact). ترجیح با مقاله‌های داوری‌شده.

## Tier 4 — گیت‌هاب (فقط بازرسی)
فقط برای سؤال پیاده‌سازی مشخص. چک‌لیست بازرسی قبل از هر برداشت:
متدولوژی؟ تست دارد؟ look-ahead bias؟ repaint؟ لایسنس؟
هر یافتهٔ Tier 4 اول EXPERIMENTAL است.
