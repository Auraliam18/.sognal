# brain/research/order-block — پایگاه دانش هوش اردر بلاک

دانش تحقیق‌محورِ ایجنت order-block (سند حمید، ۱۳ اوت، بند ۲۲–۲۵) این‌جا
می‌نشیند — **جدا از تولید**. هیچ ورک‌فلوی تولیدی این پوشه را نمی‌خواند؛
مسیر ورود به کد فقط چرخهٔ اجباری است:

QUESTION → SOURCES → EVIDENCE → HYPOTHESIS → BACKTEST → PAPER TEST →
REVIEW → MEMORY

## قواعد

- تحقیق فقط با ماشهٔ معنادار شروع می‌شود (رفتار مکرر خلاف انتظار، مفهوم
  جدید، ضعف آشکارساز، تغییر ریزساختار) — گشت‌وگذار تصادفی ممنوع.
- هر یافته یک شناسنامه دارد: منبع، URL، تاریخ برداشت، ایجنت، ادعا،
  سطح اطمینان، و وضعیت اعتبار.
- وضعیت‌های اعتبار (به ترتیب): UNVERIFIED → RESEARCHED → BACKTESTED →
  PAPER_VALIDATED → PRODUCTION_VALIDATED / REJECTED.
  **هیچ یافتهٔ UNVERIFIED بی‌سروصدا وارد منطق تولید نمی‌شود.**
- فقط دانش «جدیدِ» قابل‌استفادهٔ مجدد ذخیره شود — بازخوانی مقاله‌های
  قبلی در هر اسکن ممنوع؛ بازبینی منابع دوره‌ای یا ماشه‌ای است.
- سلسله‌مراتب منابع: `sources.md` · پرسش‌های باز: `open-questions.md` ·
  یافته‌های شناسنامه‌دار: `findings.md`.
- دیتاست تجربی (گذارهای وضعیت هر باکس) در `brain/ob/observations.jsonl`
  است، نه این‌جا — این پوشه فقط دانش، آن فایل فقط داده.
