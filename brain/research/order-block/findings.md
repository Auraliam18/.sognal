# یافته‌های شناسنامه‌دار — هوش اردر بلاک

قالب هر یافته (هیچ فیلدی حذف نمی‌شود):

```
## <عنوان کوتاه>
- منبع / URL / تاریخ برداشت:
- ایجنت ثبت‌کننده:
- ادعا (یک جمله):
- سطح اطمینان (LOW/MEDIUM/HIGH):
- وضعیت: UNVERIFIED | RESEARCHED | BACKTESTED | PAPER_VALIDATED |
  PRODUCTION_VALIDATED | REJECTED
- اندازه‌گیری (اسکریپت + نتیجه + CI):
```

هنوز یافته‌ای ثبت نشده — این فایل با اولین تحقیق ماشه‌دار پر می‌شود،
نه با کپی تعاریف عمومی.
