# کتابخانهٔ مرجع انجین‌ها — پروتکل ورود

هر انجین سه کتاب مرجع دارد (`config/engine_learning_registry.yaml`).

## قانون قطعی (سند حمید، ۱۴ اوت)

- متن کامل کتاب **فقط** از نسخه‌ای خوانده می‌شود که حمید قانونی تهیه کرده
  و در اختیار سیستم گذاشته. دانلود غیرمجاز و دور زدن paywall ممنوع.
- متن کامل کتاب **هرگز ذخیره نمی‌شود** — فقط:
  `definition` · `formula` · `assumption` · `failure_mode` ·
  `testable_claim` · `citation` (فصل/صفحه) · `research_question`
- هیچ جمله‌ای از کتاب مستقیم Rule تولید نمی‌شود؛ مسیر اجباری از
  HYPOTHESIS و BACKTESTED می‌گذرد (E18) و فقط E21 به حافظهٔ مرجع می‌برد.

## ساختار هر کتاب (وقتی حمید نسخه را داد)

```
{book_id}/
  index.yaml        ← عنوان، نویسنده، انجین‌ها، فصل‌های مرتبط، وضعیت
  chapter-notes/    ← هر فصل چند پاراگراف، نه بازتولید متن
  claims.jsonl      ← Claimهای قابل‌آزمون با citation
  citations.jsonl
```

پس از پایان هر کتاب: `BOOK_COMPLETION_REPORT` — آموخته‌ها، ایده‌های
ردشده، آزمایش‌های پیشنهادی، خلأهای باقی‌مانده.

## وضعیت فعلی

هنوز هیچ کتابی بارگذاری نشده. **منتظر نسخه‌های قانونی حمید.**
تا آن موقع، حلقهٔ دانش فقط از Source Monitor (مستندات/مقالات رایگان
رسمی) تغذیه می‌شود.
