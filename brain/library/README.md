# کتابخانهٔ دائمی — منبع مطالعهٔ ایجنت‌ها (دستور حمید، ۱۶ اوت)

منبعِ ماندگارِ مقاله‌ها و فصل‌های کتاب که ایجنت‌ها از آن می‌خوانند.
ورود فقط با **راستی‌آزمایی**: مطلبِ تأییدنشده وارد قفسه نمی‌شود.

## ساختار

- `index.jsonl` — قفسهٔ اصلی، append-only؛ هر خط یک مدخل.
- `queue.jsonl` — صف بررسی؛ هر پیشنهاد اول این‌جا می‌نشیند تا ایجنت اصلی
  صحتش را بسنجد (منبع معتبر؟ ادعا با شواهد می‌خواند؟ با قوانین هسته
  تناقض ندارد؟) بعد با status مناسب به قفسه می‌رود یا REJECTED می‌شود.

## اسکیمای مدخل (قانون ۰۳)

```json
{"id": "...", "title": "...", "source": "کتاب/نشریه/URL",
 "method": "خلاصهٔ روش در ۱-۳ جمله", "topic": "trendline|sr|smc|volume|...",
 "engine": "E07", "verified_by": "lead", "verified_at": 0,
 "status": "VERIFIED|QUEUED|REJECTED", "notes": "چرا معتبر است"}
```

## قواعد

1. **دقت قبل از ورود** — ادعای هر مطلب قبل از VERIFIED بررسی می‌شود؛
   مطلبِ بی‌منبع یا متناقض با قوانین هسته REJECTED می‌شود با دلیل.
2. مدخل حذف نمی‌شود؛ فقط status عوض می‌شود (همان قانون Conflict ماند).
3. حلقهٔ تحقیق شبانه (knowledge-loop) قفسه را می‌خواند و برداشت هر انجین
   در `brain/research/<Exx>/findings.jsonl` ثبت می‌شود.
4. ورود به Production همیشه فقط از مسیر قانون ۰۳ (backtest → CI از صفر).
