# IBS + پولبک پلاس — استراتژی هستهٔ LIAM

توالی ساختاری مورد انتظار:
شکست S/R مهم → BOS → پولبک ۱ → ادامه → BOS دوم → پولبک ۲ →
بازگشت به سطح فلیپ‌شده / OB معتبر / FVG معتبر → ارزیابی اجرا

## قوانین سخت
- ورود خودکار در پولبک ۱ ممنوع — روش حمید: «منتظر پولبک دومش می‌مانم».
  (آزمایش پولبک اول جدا در دفتر experiments اندازه می‌شود؛ تا CI از صفر
  رد نشده، قانون عوض نمی‌شود.)
- CHoCH داخل پولبک ۱ یا ۲ می‌تواند ایندوسمنت/تله باشد، نه برگشت.
  CHoCH صعودی داخل پولبک نزولی = تلهٔ لانگ محتمل. منطق نزولی قرینه است.

## چک‌لیست پیش از ورود
OB تازه است یا مصرف‌شده؟ FVG تازه است یا پرشده؟ نقدینگی پشت ساختار هست؟
سطح شکسته فلیپ شده؟ حرکت قبلی displacement بود یا ضعیف؟ پولبک سالم است یا
مخرب؟ نشانهٔ ایندوسمنت هست؟ رفتار کندل و حجم چه می‌گوید؟

## IBS
تأیید است، نه سیگنال مستقل: محیط لانگ IBS ≤ ۰.۳۰ · محیط شورت IBS ≥ ۰.۷۰.
هیچ معامله‌ای صرفاً به دلیل رسیدن IBS به آستانه صادر نمی‌شود.

## ONE-IDM / ویک (ماژول جدا — آزمایشی)
روند غالب + زون عرضه/تقاضای معتبرِ دور + یک ایندوسمنت معنادار + نفوذ ویک
به زون + تأیید تایم بالا. ویک بدون معنای ساختاری = هیچ. وضعیت فعلی:
دفتر inducement با میانگین منفی — نزدیک حذف، حکم فقط با CI زیر صفر.

پیاده‌سازی: موتور در index.html/engine.js + hamid/cycle.py (روش حمید) +
scan.py (ibs/smc). سنجش: backtest.py (کندل واقعی) + دفترهای paper.py.
