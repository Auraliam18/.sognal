# حاکمیت یادگیری، تحقیق و حافظه

چرخه‌ی رسمی:

`OBSERVATION → QUESTION → SOURCES → EVIDENCE → HYPOTHESIS → BACKTEST → WALK_FORWARD → PAPER → SHADOW → REVIEW → VERSIONED_PROMOTION`

- یادگیری از نظر موضوعی محدود نمی‌شود، اما ورود آن به Production کاملاً کنترل می‌شود.
- Random browsing و خواندن کل GitHub ممنوع است؛ هر تحقیق سؤال دقیق و Source Hierarchy دارد.
- وضعیت Claim: UNVERIFIED, RESEARCHED, BACKTESTED, PAPER_VALIDATED, SHADOW_VALIDATED, PRODUCTION_VALIDATED, REJECTED.
- تنها Memory Curator می‌تواند Canonical Memory را تغییر دهد.
- Idle compute به Replay/Backtest/Research Queue اختصاص می‌یابد، نه فراخوانی دائمی LLM.
- هر Claim: source, URL/reference, retrieved_at, agent, claim, evidence, sample_size, regime, confidence, validation_status, strategy_version.
- Conflict حذف نمی‌شود؛ Versioned و قابل مشاهده می‌ماند.
- تغییر وزن یا Threshold باید Out-of-sample و Regime split داشته باشد.
