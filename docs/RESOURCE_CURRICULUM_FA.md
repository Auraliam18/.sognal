## روش مطالعه‌ی Agent

1. سؤال مشخص بساز.
2. Tier 1/2 را اول بررسی کن.
3. فقط بخش مرتبط کتاب/مقاله را بخوان؛ خلاصه‌ی قابل بازیابی بساز، نه کپی متن.
4. Claim و Citation/URL را ثبت کن.
5. یک فرضیه‌ی قابل رد و Test Plan بساز.
6. نتیجه‌ی منفی را هم ذخیره کن.
7. Update فقط در صورت تغییر Source یا ایجاد سؤال جدید؛ تکرار مقاله‌ی قبلی ممنوع.
