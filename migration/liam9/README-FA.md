# جداسازی کامل لیام تریدر ۹ — نقشهٔ ۴ قدمی حمید

مشکل: دو پنل در یک ریپو = تصادم دائمی (ویرایش فایل‌های مشترک، مرج،
قاطی شدن حافظه و برند). راه‌حل: ریپوی مستقل. سهم تو فقط ۴ قدم:

1. ✅ **انجام شد** — اکانت جدید `Auraliam` + ریپوی `liam-trader-9`.
   ⚠️ دو نکتهٔ اکانت جدید:
   - **Pages روی ریپوی خصوصیِ اکانت رایگان کار نمی‌کند.** اگر پنل وب
     می‌خواهی: Settings → General → پایین صفحه Change visibility →
     Public. (ریپوی قدیمی هم Public است؛ هیچ Secret ای داخل کد نیست.)
   - **کلود هنوز اکانت جدید را نمی‌شناسد** — قدم ۲ همین را حل می‌کند.

2. **اتصال کلود به اکانت جدید** — در claude.ai/code → New session →
   در انتخاب ریپو روی «Add account / Manage access» بزن → با اکانت
   `Auraliam` وارد GitHub شو → به `liam-trader-9` دسترسی بده →
   جلسه را روی همان ریپو باز کن و فقط بنویس:
   «طبق migration/liam9 از ریپوی قدیمی مهاجرت کن»
   اسکریپت آماده است — خودش همه‌چیز را می‌آورد، هویت را جدا می‌کند،
   کامیت و پوش می‌کند.

3. **دو Secret تلگرام** — در ریپوی جدید: Settings → Secrets and
   variables → Actions → New secret:
   `TELEGRAM_BOT_TOKEN` و `TELEGRAM_CHAT_ID`.
   مقدار توکن را GitHub نشان نمی‌دهد — از جایی که اول گرفتی بردار
   (@BotFather در تلگرام؛ اگر گم شده همان‌جا token دوباره می‌دهد).
   chat id همان قبلی است.

4. **Pages** — Settings → Pages → فعال کن.
   آدرس پنل جدید: `auraliam.github.io/liam-trader-9/` (اکانت جدید Auraliam)

بعد از سبز شدن اولین چرخه و اولین سیگنال امضادار در ریپوی جدید، این چت
دیگر به ریپوی قدیمی دست نمی‌زند — آن‌جا تماماً مال پنل دیگر می‌شود و
هیچ مرجی بین دو پنل ممکن نیست.

## چه می‌آید

پنل (index/sw/manifest/آیکون‌ها) · کل موتور پایتون (سیکل، دروازهٔ روند،
کارمزد، سایز، کیل‌سوییچ، reconciliation، دفتر انتظار، کالبدشکافی باخت،
پاسبان، کانکتور داشبورد) · ورک‌فلوها · قوانین/اسکیل‌ها/ایجنت‌ها ·
کتابخانه + حافظه + research · TradingView و n8n · تست‌ها (۵۰+).
