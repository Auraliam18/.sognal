# حمید روی TradingView 📊

موتور سیگنال حمید به زبان **Pine Script** ترجمه شده تا مستقیم داخل چارت TradingView اجرا شود.

هر ارزی که باز کنی، در هر تایم‌فریمی که بگذاری — موتور همان‌جا روی همان چارت تمام محاسبات را انجام می‌دهد.

---

## نصب (۲ دقیقه)

1. وارد [tradingview.com](https://www.tradingview.com) شو و یک چارت باز کن
2. پایین صفحه روی **Pine Editor** بزن
3. محتوای فایل `hamid-smc.pine` را کامل کپی کن و داخل ادیتور پیست کن (کدهای قبلی را پاک کن)
4. روی **Save** بزن و یک اسم بگذار: `حمید SMC`
5. روی **Add to chart** بزن

تمام. حالا موتور روی چارتت فعال است.

---

## چه چیزی می‌بینی؟

| المان | معنی |
|---|---|
| 🟩🟥 جعبه رنگی | منطقه **Order Block** — جایی که انتظار واکنش قیمت داریم |
| خط‌چین + برچسب `BOS` | **شکست ساختار** — سطحی که قیمت شکست |
| برچسب `Choch` | **تغییر کاراکتر** — شروع پولبک |
| برچسب `LONG` / `SHORT` | سیگنال تأییدشده |
| پس‌زمینه رنگی | قیمت **داخل** منطقه OB است — لحظه حساس |
| خط سفید / نقطه‌چین / خط‌چین | ورود / حد ضرر / اهداف |

### جدول تحلیل (گوشه بالا-راست)

| ردیف | توضیح |
|---|---|
| جهت | LONG / SHORT / NEUTRAL |
| امتیاز | امتیاز نهایی + بوست IBS داخل پرانتز |
| وضعیت | SIGNAL / WAITING / WATCHING / APPROACHING / RANGE |
| کیفیت IBS | کیفیت ستاپ ساختاری ۰ تا ۱۰۰ |
| ساختار | BOS ↑↓ → Choch → ✅ (کندل تأیید) |
| منطقه OB | محدوده دقیق قیمتی |
| ورود / حد ضرر / اهداف | سطوح معاملاتی |
| تایم‌فریم‌ها | چند تا از ۳ تایم‌فریم هم‌جهت‌اند |

## تایم‌فریم‌ها — چطور کار می‌کند؟

موتور خودش را با تایم‌فریم چارت تو تطبیق می‌دهد:

- **تایم‌فریم چارت** (وزن ۴۵٪) — هر چیزی که تو انتخاب کنی
- **HTF اول** = ۴ برابر چارت (وزن ۳۵٪)
- **HTF دوم** = ۱۶ برابر چارت (وزن ۲۰٪)

یعنی اگر روی **۱۵ دقیقه** باشی → ۱۵m + ۱h + ۴h
اگر روی **۵ دقیقه** باشی → ۵m + ۲۰m + ۸۰m

ضرایب را می‌توانی در تنظیمات اندیکاتور عوض کنی.

## آلارم (حتی وقتی خوابی) 🔔

روی چارت راست‌کلیک → **Add alert** → در قسمت Condition اندیکاتور `حمید SMC` را انتخاب کن.

آلارم‌های موجود:

- سیگنال LONG
- سیگنال SHORT
- قیمت وارد OB شد
- BOS صعودی / نزولی

### Webhook

اگر تیک **Webhook URL** را بزنی، هنگام سیگنال این JSON ارسال می‌شود:

```json
{
  "engine": "hamid-smc",
  "symbol": "BTCUSDT",
  "tf": "15",
  "direction": "LONG",
  "score": 78.4,
  "ibs_quality": 85,
  "in_ob": true,
  "structure": "bull",
  "entry": 105240.5,
  "sl": 104180.0,
  "tp1": 106830.0,
  "tp2": 107890.0,
  "tf_agree": 3
}
```

می‌توانی این را به تلگرام، دیسکورد یا هر سرویس دیگری وصل کنی.

## تفاوت با پنل حمید

| | پنل حمید (وب) | حمید روی TradingView |
|---|---|---|
| تعداد ارز | ۲۵ ارز اسکن خودکار | ارزی که باز کرده‌ای |
| اجرا | هر ۵ دقیقه خودکار | لحظه‌ای، روی هر کندل |
| فیلتر حجم | دارد (۲۵M دلار) | ندارد (TradingView حجم دلاری نمی‌دهد) |
| دامیننس / ترس‌وطمع | دارد | ندارد |
| نمایش گرافیکی OB | ندارد | کامل روی چارت |

**بهترین کار: هر دو را با هم استفاده کن.** پنل حمید بازار را جارو می‌کند و ارز مستعد را پیدا می‌کند؛ بعد همان ارز را در TradingView باز کن تا ساختار دقیقش را ببینی.
